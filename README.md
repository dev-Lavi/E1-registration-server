💸 CashCue
CashCue is a full-stack expense tracking application designed to help users manage their personal finances efficiently. With an intuitive interface and robust backend, users can record, categorize, analyze, and forecast their expenses seamlessly.

🚀 Features
User Authentication: Secure registration and login system.

Expense Management: Add, edit, and delete expenses with ease.

Categorization: Organize expenses into customizable categories.

Data Visualization: Interactive charts to analyze spending patterns.

Responsive Design: Optimized for both mobile and desktop devices.

Secure Data Storage: JWT-based authentication ensures data security.

Expense Forecasting: Predicts expenses for the next day and upcoming month based on historical data and spending habits.
